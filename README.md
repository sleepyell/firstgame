# Smart Grocery & Budget Safety Tracker (Studi Kasus Rian - DT2 Pertemuan 15)

Aplikasi Web Mobile PWA Smart Grocery Tracker terintegrasi Firebase Cloud Firestore, dirancang untuk evaluasi Sumatif Daily Test 2 (DT2).

Fitur Utama:
- **SRS F-01:** Form Input Item Pokok, Lokasi Toko (`Lotte Mart Grocery - Puri Indah`) & Selector Tanggal.
- **SRS F-02:** Penggandaan Kuantitas Otomatis Tanpa Delay (Perhitungan Subtotal & Total Realtime).
- **SRS F-03:** Penanganan Diskon Bertingkat Kompound (*Compound Discount* $50\% + 20\%$).
- **SRS F-04:** Indikator Komparasi Fluktuasi Harga Realtime (Patokan Lotte Mart Puri Indah Sept 2026).
- **SRS F-05:** Proteksi Batas Dompet Rp 350.000, Tahan Reload Browser (F5), dan Sinkronisasi Multi-Device `onSnapshot`.
